# Lessons learned

This directory stores long-term lessons, findings, and improvements discovered
during development. Each lesson should be a markdown file with a clear title,
date, context, and actionable guidance for future LLMs and humans.

## Guidelines

- Create a new file per lesson (e.g. `2026-10-14-docker-port-conflict.md`).
- Include: Goal/Context, Problem, Solution, Verification, Takeaway.
- After fixing a bug or discovering a non-obvious pattern, write a lesson.
- Keep it concise and factual.
