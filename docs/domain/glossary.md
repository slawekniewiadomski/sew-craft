# Glossary

Sewing and CAD terms used across the codebase. Prefer these words in code,
UI copy and specs.

| Term                            | Meaning                                                                                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Block / sloper**              | A basic fitted pattern with no design ease, used as a base to modify.                                                                                                                                              |
| **Pattern**                     | The drafting document a project owns: pieces, entities, constraints, assemblies and tabs. One per project in v1. It has no name of its own; the project name is used everywhere it is shown.                       |
| **Piece**                       | The container for everything drawn on one pattern piece. It owns its entities, constraints and texts, carries a name, a cut quantity and per-edge allowances, and may start empty before its cut loop is captured. |
| **Edge**                        | A single line, curve or arc that forms part of a piece boundary.                                                                                                                                                   |
| **Assembly**                    | A named layout that places **instances** of the pattern's pieces. It owns no geometry: each instance references a piece and stores an anchor position, rotation and mirror flag.                                   |
| **Instance**                    | One placed copy of a piece inside an assembly. Editing the piece updates every instance of it.                                                                                                                     |
| **Tab**                         | One entry in the workspace's bottom tab bar: a piece or an assembly. The order is stored in the document (`tabs`) so reordering is undoable.                                                                       |
| **Seam match**                  | Two or more **sides** sewn together on an assembly, ordered by layer. A side is a run of consecutive stitch-loop edges on one instance; a three-layer seam is one record, not three pairwise seams.                |
| **Seam side**                   | One run of a seam match: an instance, the consecutive `Piece.edges` it covers, and whether it is traversed against its authored order (`reversed`).                                                                |
| **Finished edge**               | An instance edge deliberately not sewn to anything, marked `hem`, `binding`, `fold` or `opening`. It is the boundary of the sewn object.                                                                           |
| **Sewability check**            | The advisory report on the assembly tab: every edge sewn once or finished, every seam's sides within 5 mm unless eased, and every reference resolvable. Errors make the pattern "not sewable"; warnings do not.    |
| **Zipper**                      | Modelled as a **seam**, not as two `opening` edges, so a pouch stays a closed shell for a future 3D preview. A zipper strip is an ordinary piece sewn between the two tape edges.                                  |
| **Anchor (instance)**           | The piece-local point an instance is positioned and rotated around: the centre of the piece's derived stitch-loop bounds, with an owned-points fallback.                                                           |
| **Drawing**                     | A future tab type for technical sheets, tables and title blocks. The `+` menu reserves its place but it is disabled.                                                                                               |
| **Role**                        | How an ordinary sketch entity is used: `cut` (default), `construction` (a guide) or `annotation` (a sewing mark). Text is annotation by definition.                                                                |
| **Construction geometry**       | A guide point/line/curve with `role: 'construction'`; never cut or exported as a cut edge.                                                                                                                         |
| **Annotation geometry**         | Ordinary sketch geometry with `role: 'annotation'` — a rivet point, velcro rectangle or strap outline. Never a cut edge, never part of a loop, never exported in this change.                                      |
| **Annotation text**             | A `text` entity: one line placed at a point of its piece, with alignment, rotation, size and an optional leader that draws a rule and a filled arrow to its target. Canvas-only until the export follow-up.        |
| **Stitch loop**                 | A piece's boundary as drawn: what you sew on, or the fold at a finished edge.                                                                                                                                      |
| **Cut loop**                    | The stitch loop offset outward per edge by its allowance and joined at every corner; what you cut.                                                                                                                 |
| **Cut edge**                    | One whole straight loop edge addressed as an anchor (`{ edge, at: 'edge' }`), resolved to that edge's **own** cut segment.                                                                                         |
| **Cut line**                    | The infinite line through a cut edge's segment: the source line plus that edge's cut-distance offset.                                                                                                              |
| **Cut-distance offset**         | How far the cut line sits from the stitch line: the edge's finished `width`, or `2 × width` for a double fold.                                                                                                     |
| **Allowance**                   | A per-edge strip on a piece: `kind` (`seam`, `single` fold, `double` fold) plus a finished `width`.                                                                                                                |
| **Finished width**              | The visible width of a seam or hem. The cut distance is derived: `width`, or `2 × width` for a double fold.                                                                                                        |
| **Fold line**                   | The turn line a double fold needs, at the finished width inside the cut line.                                                                                                                                      |
| **Cut dimension**               | A read-only dimension measuring a piece's cut loop; derived from the stitch loop plus allowances.                                                                                                                  |
| **Seamline point**              | A derived, non-editable corner of a piece loop used as a dimension anchor; it is resolved from the loop on every read, never stored as an entity or solver variable.                                               |
| **Point-to-edge cut dimension** | A cut dimension from a corner to its perpendicular foot on a straight edge's cut line.                                                                                                                             |
| **Seam allowance**              | Extra material beyond the stitch line added to edges before cutting (commonly 1–1.5 cm). Piece allowances are the only path in schema 0.4; the legacy `seams` field is gone.                                       |
| **Stitch line**                 | The line the seam is actually sewn along, inside the seam allowance.                                                                                                                                               |
| **Dart**                        | A fold of fabric shaping it to the body, taken up from an edge to a point.                                                                                                                                         |
| **Grainline**                   | Arrow marking how the piece aligns with the fabric's lengthwise grain.                                                                                                                                             |
| **Notch**                       | Small mark on an edge for matching pieces when sewing.                                                                                                                                                             |
| **Centre line**                 | A straight mark across a piece — centre front, centre back or a fold — drawn between two snapped points; labelled with the Text tool.                                                                              |
| **Mark**                        | A sewing mark on a piece: a notch or a centre line. Drawn and exported, never a cut edge, and resolved from the piece on every read so it follows the allowance.                                                   |
| **Truing**                      | Adjusting adjoining edges so seams match in length and shape.                                                                                                                                                      |
| **Ease**                        | Extra room between body and garment; may be design or fitting ease.                                                                                                                                                |
| **Grading**                     | Producing a range of sizes from one pattern by moving points.                                                                                                                                                      |
| **Facing / lining**             | Separate pieces finished to the inside of a garment.                                                                                                                                                               |
| **Nesting / layout**            | Arranging pieces on fabric of a given width to minimise waste.                                                                                                                                                     |

## Geometry terms

| Term                     | Meaning                                                                                                                                                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Entity**               | A point, line, curve, circle or arc in the geometry document.                                                                                                                                                            |
| **Constraint**           | A relation the solver must satisfy (coincident, distance, …).                                                                                                                                                            |
| **Dimension**            | The CAD rendering of a `distance` constraint: extension lines, a chevron line, and an editable value.                                                                                                                    |
| **Anchor**               | One end of a dimension: a point, or a whole straight line whose infinite supporting line is measured to.                                                                                                                 |
| **Set dimension**        | A dimension with a literal `value`: the solver drives the span and the label renders without parentheses.                                                                                                                |
| **Driven dimension**     | A dimension with no `value` and no `reference`: it measures the sketch, renders in parentheses and muted gray, and adds no solver equation.                                                                              |
| **Referenced dimension** | A dimension whose `reference` names another dimension: its effective value is derived from that source, it renders in square brackets and blue, and it drives the span with the resolved number.                         |
| **Broken dimension**     | A referenced dimension whose source is missing, driven or otherwise unresolvable: it keeps the last known reading, renders in square brackets with red and a warning glyph, and adds no solver equation until re-linked. |
| **Corner round**         | A tangent arc (fillet) replacing a sharp corner between two lines; both lines are trimmed to their tangent points.                                                                                                       |
| **Tangent point**        | The point where a line ends and a corner round's arc begins.                                                                                                                                                             |
| **Sharp corner**         | The original intersection of two lines, kept as a construction point while a corner round references it.                                                                                                                 |
| **Round bridge**         | The derived arc a corner round contributes to a piece loop between its two trimmed edges; never stored on the piece.                                                                                                     |
| **Rounded piece corner** | A piece loop corner where a committed corner round supplies the bridge.                                                                                                                                                  |
| **Corner allowance**     | An optional cut width stored on a piece for one corner round; the crescent uses it instead of the width its two adjacent edges agree on.                                                                                 |
| **Split crescent**       | The two halves a round's band becomes when its two edges carry different allowances; each half belongs to the edge on its side and is picked as that edge.                                                               |
| **Allowance region**     | One selectable part of a piece's allowance band on the canvas: an edge strip (with half of each sharp wedge) or a round crescent.                                                                                        |
| **Feature tool**         | A tool that modifies existing sketch geometry rather than adding to it (Round corner, Notch, Centre line); lives in the **Features** ribbon group.                                                                       |
| **Derived dimension**    | A dimension computed from generated geometry and owning no solver variable; a cut dimension is one, and the solver never receives it.                                                                                    |
| **DOF**                  | Degrees of freedom left in a sketch.                                                                                                                                                                                     |
| **Converged**            | The solver reduced all residuals below tolerance.                                                                                                                                                                        |
| **Residual**             | The signed error of one constraint at the current coordinates.                                                                                                                                                           |

## Units

Everything is stored in **millimetres** as floats. Radians for angles. Display
units (cm/in) are a frontend concern only.
